ASHFALL for Windows
===================

1. Keep this whole folder together (ASHFALL.exe needs the files next to it).
2. Double-click ASHFALL.exe.
3. The first time, Windows may say "Windows protected your PC".
   Click "More info", then "Run anyway". It only asks once.
   (This appears because the game is not signed with a paid Microsoft certificate.)
4. If Windows Firewall asks, allow ASHFALL on private networks so games on your Wi-Fi show up.

Updates download by themselves when you open the game.
Online: pick ONLINE TEAM DEATHMATCH or ONLINE FREE-FOR-ALL, then QUICK PLAY,
or type a private code that your friends type too.
F11 = full screen.
